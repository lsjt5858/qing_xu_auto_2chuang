# 已有目标视频时跳过处理

## 背景

`VideoAnalyzer` 每次初始化都会创建一个带时间戳的新输出目录。重复运行同一个源视频时，即使历史 `output` 目录已经包含清洗后的目标视频，当前流程仍会重新执行去字幕、分镜、音频提取和转录。

## 目标

处理本地视频前，检查输出根目录中是否已经存在该视频对应的 `video_no_subtitles.mp4`。如果存在，跳过该视频的整个处理流程。

## 非目标

- 不校验历史分镜、音频、转录或报告是否完整。
- 不计算源视频内容哈希。
- 不增加强制重跑参数。
- 不改变现有输出目录命名和产物结构。

## 匹配规则

源视频以文件名主干作为当前项目内的身份标识。例如：

```text
源视频：/videos/example.mp4
产物目录：output/example_20260916_134659/
目标视频：output/example_20260916_134659/video_no_subtitles.mp4
```

候选目录必须严格符合 `<视频名>_YYYYMMDD_HHMMSS`，避免把名称前缀相同的其他视频误判为同一视频。候选目录中只要存在普通文件 `video_no_subtitles.mp4`，即视为已经产出目标视频；不依赖 `report.json`，从而覆盖只执行去字幕或后续步骤中断的历史任务。

## 处理流程

`BatchProcessor.process_video()` 在检查输入文件存在后、创建 `VideoAnalyzer` 前执行历史产物查询：

1. 遍历配置的输出根目录下一级子目录。
2. 按严格的目录命名规则匹配当前视频。
3. 检查候选目录中的 `video_no_subtitles.mp4`。
4. 命中后打印跳过原因和已有文件路径，直接返回成功。
5. 未命中时保持现有处理流程不变。

跳过发生在 `VideoAnalyzer` 初始化之前，因此不会创建新的时间戳目录，也不会执行去字幕、场景分割、音频提取、转录、报告生成或剪映导出。

## 错误处理

- 输出根目录不存在或不是目录时，视为没有历史产物并正常处理。
- 无关文件、命名不合规的目录和缺少目标视频的目录均忽略。
- 输入文件不存在时继续沿用现有错误行为，不因历史产物而返回成功。

## 测试

新增 `BatchProcessor` 单元测试，至少覆盖：

1. 符合命名规则且存在目标视频时，返回成功且不初始化 `VideoAnalyzer`。
2. 目录存在但缺少目标视频时，继续初始化并执行正常流程。
3. 名称仅为前缀匹配的其他视频目录不会触发跳过。
4. 输出根目录不存在时继续正常处理。
