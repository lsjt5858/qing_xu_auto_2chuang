# `output` 剧本库结构分析与二创指南

> 分析日期：2026-07-19  
> 分析范围：`output` 下 13 个案例目录  
> 分析依据：目录标题、`transcript.txt`、`transcript_detailed.json`、`report.json`、视频均匀采样画面  
> 重要限制：现有 Whisper 转录存在大量同音误识别、重复字和长段幻听。本报告分析“情节与情绪结构”，不把错误转录当作可靠原台词。

## 一、先给结论

这个库当前不是“13 个现实案例剧本”，而是一个混合素材池：

- 13 个案例目录；
- 9 个目录有视频、逐字稿、时间轴和报告；
- 4 个目录完全为空，只有目录标题，不能分析正文；
- 9 个可读条目中，7 个含叙事样片，2 个主要是制作教程/爆款拆解；
- 只有《爸爸给了我生命……》在标题中明确声称“根据真实事件改编”；
- 《外星人要接我走》明确声明为原创虚构；
- 《钟馗嫁妹》、西游题材显然是神话或寓言改写；
- 其余条目不能仅凭“情感真实”认定为真实事件。

因此，二创时应把“真实感”和“真实事件”分开：可以写得像现实，但没有可核验来源时，不要标注“根据真实事件改编”。

这个库最值得复用的不是某个具体情节，而是一条稳定的情绪公式：

> **反常行为 → 观众误解 → 关系债累积 → 爱的动机延迟揭晓 → 不可逆选择 → 用物件或一句话留余韵**

典型例子：拼命增重，后来才知道是为达到捐献门槛；故意多坐三站，后来才知道是不舍得分开；嘴上说姐姐出嫁很开心，却迟迟不肯开门；用“外星招聘”包装独居老人真正需要的陪伴。

## 三、逐案文案结构

### C01《钟馗嫁妹》爆款拆解

**定位**：神话人物承载现实家庭压迫、婚配与救赎议题；文件本身还含拉片分析画面，因此既是故事参考，也是视听拆解参考。

**可辨识结构**：

1. 用钟馗/妹妹关系建立神话钩子。
2. 把妹妹放入贫困、婚配受限或家庭控制的现实处境。
3. 妹妹对爱情、自主选择或正常生活的愿望与家族规则冲突。
4. 暴力、逼迫或悲剧后果升级。
5. 钟馗从旁观、迟到或无力，转为惩恶/救妹。
6. 用神话复仇和视觉奇观完成情绪宣泄。

**情绪发动机**：古典神祇的强大，反衬普通女性现实中的无力；“能捉天下鬼，却未必及时救得了最亲的人”形成主题反差。

**二创可复用**：神话角色进入现实议题、亲人救赎、迟到的保护、现实苦难与超自然宣泄。

**不要照搬**：钟馗、嫁妹、特定婚配冲突、相同复仇路径和标志性视听画面同时出现时，会过于接近原作。

### C02《外星人要接我走》

**一句话故事**：外星人以“荒星招聘”为名邀请一位农村独居老人，荒诞福利逐条揭开老人真正缺少的是有人关心、有人听他说话。

**结构**：

1. **异常钩子**：外星人说要接老人走。
2. **喜剧质疑**：老人怀疑是骗子，外星人用一本正经的招聘话术回应。
3. **现实画像**：采空区、人口外流、长期无人探望，老人被称为“星际孤独样本”。
4. **条件升级**：荒星没水没路、环境恶劣，老人反而觉得自己很擅长忍耐。
5. **福利反转**：恒温房、每日体检、每天固定陪聊半小时。
6. **核心物件**：“想念接收器”——只要宇宙中有人想起他就会响。
7. **刺痛结尾**：现实通讯/话费提示打断幻想，重新落回孤独。

**情绪发动机**：用科幻和冷幽默降低说教感，再把“福利”逐条翻译成老人现实中缺失的照护。

**最可复用 DNA**：荒诞机构认真解决一个极普通的人间问题；笑点和泪点使用同一套信息。

### C03“爸爸给了我生命……”

**一句话故事**：一个体重不足的男孩不断暴食增重，观众起初以为他贪吃或被嘲笑，后来才知道他在争取达到救父所需的捐献门槛。

**结构**：

1. **反常开场**：孩子已经吃不下，仍逼自己继续吃。
2. **外部误解**：同学取笑他发胖，家人担心他吃坏身体。
3. **隐瞒动机**：孩子不解释，继续称重、进食和等待。
4. **门槛揭示**：父亲病危，孩子体重不足，暂时不符合捐献要求。
5. **蒙太奇升级**：三个月增重，轻微胃痛也不停止。
6. **达成目标**：体重数字过线，孩子奔向病房/手术室。
7. **情绪峰值**：孩子完成捐献或救治步骤，父亲得知真相。
8. **价值句**：“爸爸给了我生命，现在换我救他。”

**情绪发动机**：先让观众误判行为，再重写前面所有“吃”的镜头；动作重复承担时间流逝和牺牲强度。

**风险**：本地材料无法可靠确认具体医疗项目。二创涉及器官、骨髓或干细胞捐献时，必须单独核实年龄、体重和医学条件，不要把转录误词写成医疗事实。

### C05 白血病、分手与抢婚长片

**一句话故事**：一对从学生时代走到创业期的恋人准备结婚，男主被确诊急性白血病后隐瞒病情、设计分手；女主被推向另一场婚姻，男主最终后悔替她做决定，带着她喜欢的白婚纱赶去阻止婚礼。

**八段结构**：

1. **青春承诺**：毕业、恋爱、关于婚姻的玩笑和约定。
2. **共同吃苦**：租便宜房、摆摊/卖鞋、用小生意积累未来。
3. **幸福预演**：试穿白婚纱、筹彩礼、准备见家长。
4. **命运打断**：急性白血病诊断，治疗时间不确定。
5. **现实阻力**：女方父母要的是一生依靠，而男主无法保证。
6. **主动伤害**：男主设计“变心”戏码，希望女主恨他并离开。
7. **错误后果**：女主答应别人，红色婚服与她喜欢的白婚纱形成视觉对立。
8. **迟到纠错**：朋友点醒男主；他离院、取白婚纱、赶往婚礼，坦白“我自私地替你决定了”。

**情绪发动机**：“为你好”的隐瞒其实剥夺了爱人的选择权。真正的主题不是抢婚，而是亲密关系里谁有权决定共同命运。

**优点**：前半段有足够生活细节，后半段反转才有重量；白婚纱/红婚服是清晰的视觉母题。

**问题**：情节叠加较多——贫穷、彩礼、父母反对、绝症、假出轨、另嫁、抢婚、病危——容易变成连续催泪按钮。二创应删掉至少两层巧合，把主题集中在“隐瞒是否等于爱”。

### C08《三站》

**一句话故事**：女儿翻到父亲年轻时的照片，母亲讲起火车上的初遇：她因为对年轻父亲心动，没敢开口，宁愿错过自己的站，多坐了三站。

**结构**：

1. **家庭钩子**：女儿发现“帅哥照片”，母亲揭晓那是年轻时的父亲。
2. **回忆入口**：旧照片把现在切到过去。
3. **偶遇建立**：绿皮火车、行李、邻座、短暂帮助或交谈。
4. **情感动作**：偷看、相机、欲言又止。
5. **标题兑现**：母亲没有及时下车，为了多相处一会儿多坐三站。
6. **缘分回收**：父亲再次出现/找到她，照片成为关系证据。
7. **回到现在**：女儿调侃，年老父母的日常接住年轻时的浪漫。

**情绪发动机**：不靠大灾难，只靠一个很小、很具体、能被记一辈子的选择。“三站”同时是标题、动作、时间和爱情尺度。

**最适合二创的部分**：旧物打开父母隐藏的人生；把抽象的爱压缩成一个可计数单位，例如三站、两公里、七分钟、最后一班车。

### C09 姐姐出嫁、弟弟不肯开门

**一句话故事**：从小和姐姐打闹的弟弟嘴上说姐姐嫁走后自己就能独占电脑，却在接亲时守着门不肯开，暴露真正的不舍。

**结构**：

1. **童年压缩**：零食、冰棍、电视遥控器、打闹，快速建立姐弟史。
2. **婚礼当天**：家人打趣“姐姐要被别人带走了”。
3. **嘴硬防御**：弟弟反复说自己很开心，列举姐姐离开后的好处。
4. **行为背叛台词**：他守门、拖延，不让接亲队伍进入。
5. **情绪泄洪**：门打开或姐姐离开时，他终于哭出来。
6. **余韵**：长大后仍记得那个不敢承认离别的自己。

**情绪发动机**：台词说“不在乎”，动作说“别走”。人物不需要解释，反差本身就是文案。

### C10 第一视角亲情短片教程

这不是单一现实案例，而是“教程 + 母亲 POV 看儿子成长”的制作示范。

**教程提炼出的结构**：

1. 选母爱、父爱、成长、离别等高共鸣关系。
2. 固定一个人的第一视角，让镜头就是人物眼睛。
3. 用多个年龄节点压缩几十年。
4. 每个节点只保留一个代表动作或一句关系台词。
5. 用相同人物特征、手部、环境物件维持时间连续性。
6. 结尾回收开场称呼、动作或物件。

**注意**：第一人称不是把旁白写成“我”。画面中不能同时出现 POV 主体的完整正脸；动作应写成“对方朝镜头伸手”“镜头低头看到自己的手”。

### C12 百万爆款第一人称教程

这也是教程条目，样片核心为留守女孩/母亲缺席的成长经历。

**样片结构**：

1. 小女孩被同伴排斥或嘲笑“妈妈不要她”。
2. 奶奶/家人提供有限但稳定的照顾。
3. 女孩不断等待母亲，时间通过年龄和重复问句推进。
4. 母亲短暂归来，用衣服、食物或钱代替陪伴。
5. 女孩从期待走向失望，重复台词的含义发生变化。
6. 成年或某个回望节点，让观众理解“被留下”的长期影响。

**教程最有价值的规则**：POV 镜头必须把动作改写为摄像机可经历的事件；先做角色、再做场景和物件；关键镜头持续强调第一人称；对白要标清画外音，避免模型生成 POV 主体正脸。

### C13 西游神话投射的儿童救赎寓言

**一句话故事**：受困女孩遇到名叫石头的男孩，两人用孙悟空和取经故事对抗现实中的暴力；男孩长大后兑现“变成孙悟空救你出去”的承诺。

**结构**：

1. **苦难开场**：贫困、控制、饥饿或囚禁环境。
2. **伙伴出现**：女孩帮助男孩，男孩自称“石头”。
3. **神话游戏**：孙悟空、唐僧、识字和取经成为孩子理解世界的方式。
4. **承诺建立**：“等我变成孙悟空，就救你出去。”
5. **现实恶化**：成年人施暴、贩卖或转移女孩。
6. **时间跨越**：石头长大，童年承诺变成行动。
7. **营救高潮**：现实人物与神话形象交叉剪辑。
8. **诗句收束**：经卷、善恶、鬼魅和取经人把个体故事升为寓言。

**情绪发动机**：孩子用神话语言命名无法理解的恶；成年后的兑现使“想象”变成伦理行动。

**二创可复用**：经典故事不是换皮，而是人物的心理生存工具。应更换经典母题、现实议题、承诺内容和最终行动。

## 四、这批文案的共性结构

### 4.1 通用八拍

| 节拍 | 占比建议 | 功能 | 常见写法 |
|---|---:|---|---|
| 1. 异常钩子 | 0%—5% | 先制造问题 | “他明明吃不下，为什么还在吃？” |
| 2. 关系速写 | 5%—15% | 让观众快速认人 | 称呼、旧物、日常争执、一个照顾动作 |
| 3. 正常愿望 | 15%—30% | 告诉观众人物想要什么 | 结婚、陪伴、被想起、让家人活下去 |
| 4. 阻碍升级 | 30%—50% | 增加现实成本 | 疾病、距离、贫困、父母反对、离别 |
| 5. 主动选择 | 50%—65% | 人物必须做事 | 增重、隐瞒、错过车站、守门、等待 |
| 6. 信息翻转 | 65%—80% | 重写前文含义 | 原来不是贪吃、冷漠、变心或不在乎 |
| 7. 不可逆高潮 | 80%—95% | 支付代价 | 手术、离开、坦白、营救、赶到婚礼 |
| 8. 余韵回收 | 95%—100% | 让情绪停留 | 照片、婚纱、门、接收器、诗句、称呼 |

短视频不一定要机械地凑齐八拍，但必须至少具备：异常钩子、关系、主动选择、延迟揭示和余韵回收。

### 4.2 高频情绪机制

1. **先误解，后理解**：观众与配角一起误判主角。
2. **台词与动作相反**：嘴上说不爱、不哭、不在乎，动作却拼命挽留。
3. **用小事承载大爱**：吃饭、坐车、开门、试衣服、接电话。
4. **重复，但含义升级**：同一句问话、同一个动作在不同时间节点改变意义。
5. **关系债**：父母给生命、姐姐陪长大、恋人共患难、老人一生撑过艰苦。
6. **延迟解释**：越晚知道动机，前文被重写得越彻底。
7. **不可逆时间**：病情、婚礼、列车、成长、衰老让人物不能无限拖延。
8. **物件闭环**：照片、婚纱、门、体重秤、接收器、经卷承担标题和结尾。

### 4.3 高频问题

- 过度堆叠绝症、贫穷、误会、父母反对、婚礼等催泪按钮；
- 主角只有受苦，没有独特性格；
- 为了反转故意不说人话，信息差不自然；
- 医疗、法律、年代和地域细节未经核实；
- 结尾只喊价值观，没有用行动或物件完成回收；
- ASR 原稿直接入库，导致重复字、错名和错误事实污染后续生成。

### 5.2 事实来源状态必须标准化

| 状态 | 含义 | 发布时可否写“真实事件改编” |
|---|---|---|
| `REAL_VERIFIED` | 有可靠报道、当事人材料或授权记录 | 可以，仍应保护隐私 |
| `REAL_CLAIMED_UNVERIFIED` | 原视频声称真实，但本库未核验 | 不建议直接写 |
| `NETIZEN_STORY_UNVERIFIED` | 网友投稿/转述，无独立证据 | 不可以当新闻事实写 |
| `REALITY_INSPIRED` | 取材于普遍社会议题 | 写“现实议题启发” |
| `FICTION_EXPLICIT` | 作者明确声明虚构 | 不可以 |
| `FICTION_LIKELY` | 叙事作品，未提供现实来源 | 不可以 |
| `TUTORIAL_EXAMPLE` | 教程生成的示范样片 | 不可以 |

## 六、二创方法：保留情绪函数，重做因果链

### 6.1 不要只做“换名字、换城市”

一篇安全且有原创价值的二创，至少改动以下 9 个维度中的 5 个，并且必须改动“核心因果链”：

1. 关系：父子 → 师徒/邻里/陌生人；
2. 主角目标：救命 → 守住尊严/完成告别/修复误会；
3. 反常行为：增重 → 每天买两份饭/反复取消订单/给停机号码充值；
4. 观众误解：贪吃 → 浪费、冷漠、撒谎、固执；
5. 阻碍：疾病 → 迁徙、失业、听力衰退、灾后重建；
6. 场景：医院 → 菜市场、夜班公交、社区食堂、修理铺；
7. 核心物件：体重秤 → 工牌、饭盒、旧收音机、未取快递；
8. 揭示方式：医生解释 → 账单、录音、第三人证词、旧物中的时间记录；
9. 结局：成功救治 → 没赶上但完成理解、选择留下、把承诺传给下一人。

如果“人物关系 + 反常行为 + 揭示 + 高潮 + 标志台词”仍与原作一致，就不算真正二创。

### 6.2 一套可直接套用的原创生成公式

```text
现实议题
+ 一个可被镜头反复看见的反常行为
+ 一个合理的信息差
+ 一段此前欠下的关系债
+ 一个有截止时间的现实压力
+ 一次由主角主动做出的高成本选择
+ 一个能在结尾改变含义的普通物件
= 一篇有真实感、但不依赖抄情节的情绪短片
```

### 6.3 五个二创起点

这些是原创方向种子，不宣称真实事件；若要冠以“真实改编”，需先找到并核验对应素材。

#### 方向 A《停机号码》：独居老人 / 克制催泪

- 反常行为：老人每月坚持给一个早已停机的号码充值。
- 观众误解：营业员以为他记性差或被骗。
- 揭示：那是老伴生前最后使用的号码；他怕号码被重新卖给别人，仿佛最后一个“家”也被收走。
- 截止时间：运营商即将回收长期停机号码。
- 结尾物件：旧手机第一次响起，是营业员用自己的号码给他打来。
- 借鉴的是《外星人》的“孤独需要被听见”，但人物、动作、因果和结尾全部重做。

#### 方向 B《两份盒饭》：陌生人关系 / 反常行为揭示

- 反常行为：夜班保安每天买两份盒饭，却总把一份原封不动扔掉。
- 观众误解：浪费、摆阔或怪癖。
- 揭示：他把饭放在旧工地门口，等一个曾在事故中救过他、后来失联的工友；所谓“扔掉”是清洁工统一收走。
- 主动选择：工地拆除前最后一晚，他留下自己的新工作地址。
- 结尾：第二天饭盒不见，里面压着一张旧工牌。

#### 方向 C《听不见的语音》：母子 / 关系误解

- 反常行为：母亲从不回复儿子的长语音，只回一个“好”。
- 观众误解：敷衍、不理解儿子。
- 揭示：母亲听力持续下降，一直靠逐句转写软件看他的语音，却怕影响他的工作而隐瞒。
- 截止时间：儿子准备移居外地，决定不再给她发语音。
- 结尾物件：母亲第一次戴上助听器，听到的不是煽情独白，而是儿子问“今晚吃什么”。

#### 方向 D《最后一班 17 路》：父女 / 时间与空间

- 反常行为：退休司机每天收车后仍空跑最后一段线路。
- 观众误解：违规耗油、舍不得退休。
- 揭示：女儿小时候走失，最后一次被目击就在这条线；多年后他知道希望渺茫，但想让每个晚归孩子都有车回家。
- 主动选择：退休当晚，他为了送一个陌生女孩绕开交车截止时间。
- 结尾物件：女孩落下的校牌姓氏与女儿不同，故事不做廉价认亲，只完成善意传递。

#### 方向 E《修不好的一台收音机》：师徒 / 旧物回收

- 反常行为：年轻修理工连续七次告诉老人“还没修好”，其实机器早已修好。
- 观众误解：拖延、想多收钱。
- 揭示：老人每次来取机都会坐下聊天；年轻人发现老人拿走收音机后就再没有理由出门。
- 截止时间：修理铺即将关门。
- 结尾：年轻人把修好的收音机送上门，并故意留下一颗“下次再换”的旧旋钮。

### 6.4 写作质检问题

完成梗概后逐项回答：

- 前 5 秒出现的是具体行为，还是空泛苦情旁白？
- 主角在故事里做了选择，还是只被灾难推着走？
- 信息差是否合理，人物为什么此前不说？
- 揭示能否重写至少三个前文镜头？
- 去掉疾病或死亡后，关系是否仍然成立？
- 是否有一个普通物件能承担标题、转折和结尾？
- 是否至少改动了五个二创维度以及核心因果链？
- 涉及医疗、未成年人、犯罪、真实人物时，事实与隐私是否已核验？
- 没有来源时，是否避免使用“真实事件改编”？

## 八、推荐的下一步

优先从 C02《外星人要接我走》、C08《三站》和 C09 姐弟出嫁三个结构学习，因为它们分别代表：

- **荒诞外壳 + 现实内核**；
- **一个可计数的小动作 + 一生的感情**；
- **台词与行动相反的克制亲情**。

第一轮原创建议不要再选“绝症 + 分手 + 婚礼”。库里这类元素已偏多。更值得做的是独居老人、听力衰退、夜班劳动者、退休、迁徙、社区陌生人互助等现实议题，用一个反常行为和一个普通物件完成情绪翻转。
