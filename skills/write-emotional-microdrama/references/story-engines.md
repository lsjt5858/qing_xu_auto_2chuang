# 催泪情感短剧故事发动机

只有故事种子、需要换题、故事中段乏力或二创需要抽取机制时读取。每个项目只选一个主发动机；复用机制，不复制案例的具体人物、台词、道具和高潮。

## 选择表

| 发动机 | 因果核心 | 适合题材 | 必须避免 |
|---|---|---|---|
| 反常行为揭示 | 先误解重复行为，后知爱的动机 | 亲情、劳动、陌生人互助 | 用绝症直接解释一切 |
| 旧物证言 | 普通物件逐层露出过去 | 父母往事、告别、代际关系 | 一封遗书包办所有信息 |
| 台词—行动反差 | 嘴上拒绝，身体却挽留或保护 | 姐弟、伴侣、父子 | 人物只为制造误会不说人话 |
| 荒诞外壳 | 超现实制度认真解决普通缺失 | 老龄、孤独、迁徙、失业 | 奇观压过现实人物 |
| 可计数的爱 | 用距离、次数、分钟或金额丈量选择 | 爱情、陪伴、守候 | 把数字写成口号而非行动 |
| 未被听见的信息 | 错过的声音/消息改变旧判断 | 异地、代际、听力、失联 | 录音突然出现且无铺垫 |
| 习惯比记忆更长 | 身体动作保留了关系 | 老年、成长、长期照护 | 把认知障碍写成医学奇迹 |
| 经典母题投射 | 角色借神话/童话理解现实困境 | 儿童、社会寓言、成长 | 只做角色换皮和视觉模仿 |
| POV 人生压缩 | 固定视角跨越多个年龄节点 | 父母子女、成长、离家 | 时间只靠字幕、主体正脸穿帮 |
| 一地一夜 | 封闭任务迫使两人重新认识 | 低成本人物戏 | 连续争吵却没有新证据 |

## 发动机最小结构

### 反常行为揭示

```text
反常动作出现三次
→ 每次成本更高
→ 配角给出错误解释
→ 独立证据打破误解
→ 主角在被理解后仍要做选择
```

第三次不能只是重复；要增加身体、时间、金钱、关系或尊严代价。

### 旧物证言

核心物件至少承担三次功能：普通用途、制造疑问、证明真相；结尾再改变归属或用途。旧物上的文字如需精确可读，交给后期合成。

### 台词—行动反差

先让角色说出防御性台词，再用一个无法伪装的动作反驳。反差必须来自人物性格和关系历史，不是编剧故意拖延沟通。

### 荒诞外壳

超现实设定只负责重新命名现实问题，例如把“没人探望”称作某种资格。每个荒诞笑点最终都要对应一个现实缺口；结尾回到普通生活，避免用特效解决社会问题。

### 可计数的爱

选择一个观众能立刻理解的单位：三站、七分钟、两份饭、一个月一次。数字必须在开头出现、过程中产生代价、结尾改变意义。

### 未被听见的信息

信息应分散在界面状态、人物习惯、他人见证和物件中。不要直到反转才突然播放一段完整录音。

### 习惯比记忆更长

把关系写进动作顺序、摆放位置、称呼、味觉或时间习惯。结尾不要求“突然全部想起”，允许理解、陪伴或告别。

### 经典母题投射

经典故事必须是人物的心理生存工具：它帮助人物命名善恶、许下承诺或选择行动。更换母题时，同时重做现实困境、承诺、行动和结局。

### POV 人生压缩

每个年龄节点只保留一个代表动作、一句关系台词和一个状态变化。镜头就是主体眼睛：写“对方朝镜头伸手”，不用“主角看见自己站在门口”。

### 一地一夜

给两人一个必须共同完成的任务；每完成一步就出现新证据并改变权力关系。结尾用是否完成任务体现关系变化。

## 组合规则

75 秒以下只用一个发动机。75-120 秒可加入一个次发动机，但次发动机只能提供证据或结尾，不能另起一条主线。120 秒以上仍不得同时堆叠绝症、婚礼、失踪、贫穷、亲子秘密等多个极端按钮。

## 选择后的检查

- 该发动机是否能被画面和声音表达？
- 主角有没有当下目标，而非只回忆过去？
- 真相是否改变人物下一步？
- 去掉悲情音乐后，证据和选择是否仍成立？
- 更换人物姓名后，故事是否仍明显复制某个作品？若是，重做核心因果链。
