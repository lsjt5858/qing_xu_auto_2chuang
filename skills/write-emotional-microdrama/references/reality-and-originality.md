# 真实性、隐私与二创原创度

涉及真实事件、网友投稿、现有作品二创、医疗、未成年人或可识别人物时读取。

## 1. 来源状态

| 状态 | 定义 | 对外表述 |
|---|---|---|
| `REAL_VERIFIED` | 有可靠报道、当事人材料或授权记录 | 可写真实改编，并说明必要戏剧化 |
| `REAL_CLAIMED_UNVERIFIED` | 来源声称真实，本项目未核验 | 不直接写“真实事件改编” |
| `NETIZEN_STORY_UNVERIFIED` | 网友投稿或转述，无独立证据 | 写“网友故事启发”仍需避免当事实宣传 |
| `REALITY_INSPIRED` | 取材于普遍社会议题 | 写“根据现实议题虚构创作” |
| `FICTION_EXPLICIT` | 作者明确声明虚构 | 保持虚构声明 |
| `FICTION_LIKELY` | 叙事作品但没有现实来源 | 不写真实改编 |
| `TUTORIAL_EXAMPLE` | 教程生成的示范样片 | 不写真实改编 |

建立来源台账：原链接、作者/发布者、发布日期、事实来源、授权范围、可识别信息、待核验项。网页标题和发布话术只能证明“对方这样声称”，不能单独证明事件真实。

## 2. 事实与表达分离

事实本身与具体表达不是一回事。改编前分列：

- 可使用的基本事实；
- 原作独特的场景排序；
- 标志性反常行为；
- 标志性物件；
- 关键台词和标题；
- 原作独有的反转与结局；
- 新剧本的虚构补写。

不得复制“相同关系 + 相同反常行为 + 相同揭示 + 相同高潮 + 相同价值句”的组合。

## 3. 五维以上改写

二创至少改动以下十项中的五项，并必须改变核心因果链：

1. 人物关系；
2. 主角当下目标；
3. 反常行为；
4. 观众误判；
5. 现实阻碍；
6. 时间与场景；
7. 核心物件；
8. 证据来源与揭示方式；
9. 高成本选择；
10. 结局和余韵。

在交付中写清：

```text
只复用的机制：____
已重做的核心因果链：____
与参考作品不同的至少五项：____
仍可能相似的表达：____
处理办法：____
```

## 4. 隐私与尊严

- 未成年人、病患、失踪者、普通真实人物的姓名、脸、学校、住址、电话、病历号等必须获授权或脱敏。
- 不用未授权普通人的脸或声音作为虚构角色参考。
- 多人经历合并后，不得声称为某一人的完整真实人生。
- 不把贫困、疾病、残障、老年、失踪或家庭创伤只当反转装置。
- 允许不和解、设立边界、继续生活或没有奇迹的结局。
- 互动问题不得诱导观众公开隐私、疾病或创伤史。

## 5. 医疗、法律和权威文本

医疗门槛、治疗路径、年龄限制、法律程序、公安流程、公益机构和平台要求必须核验。无法核验时改变情节或标记待核验，不用模糊旁白蒙混。

病历、鉴定、通知、聊天记录、票据、标签等关键文字应在剧本中列为后期可控文字。不要依赖图像/视频生成模型准确生成。

## 6. 发布前检查

- 现实来源状态与发布话术一致。
- 虚构补写没有被包装成新闻事实。
- 可识别人物和敏感数据已授权或脱敏。
- 医疗/法律因果已核验。
- 二创改变了核心因果链和至少五个维度。
- 没有复制标题、关键台词、标志性物件和镜头顺序的组合。
- 困境人物拥有目标、判断和选择，不只是供观众怜悯。
