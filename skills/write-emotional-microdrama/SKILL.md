# 催泪情感短剧编剧

把一段故事写成先成立、再传播、最后可生产的情感微短剧。复用情绪机制，不复制具体作品的因果链、台词、人物和标志性物件。

## 边界

- 本技能负责故事命题、人物选择、证据链、自媒体节奏、完整剧本、发布包装和下游交接。
- `wanwusheng-ai-film-director` 负责连续性审计、资产 ID、分镜、关键帧、生成模式、视频提示词、声音字幕交接和成片修复。
- 在剧本未通过故事闸门前，不用镜头、音乐或视觉奇观掩盖因果缺失。
- 除非用户明确要求，不在本阶段扩写逐镜头生成提示词。

## 默认规则

- 用中文输出。保留用户给定的平台、时长、画幅、人物关系、事实边界和结局倾向。
- 区分 `来源事实`、`用户锁定`、`创作虚构`、`制作推断`、`待核验`。
- 平台不等于画幅。用户未指定画幅时只给候选并标记 `制作推断`，不得因为“抖音”而静默锁定 9:16。
- 没有可靠来源时，不写“真实事件改编”；可写“根据现实议题虚构创作”。
- 只选一个核心情感命题和一个主故事发动机；时长充足时最多增加一个次发动机。
- 情绪峰值依赖选择、证据和细节，不默认使用绝症、死亡、失忆、婚礼抢人、突降亲属或权威文件。
- 让困境人物至少做一次有尊严、有判断、需要付出代价的选择。
- 旁白只补画面无法表达的信息；抽象句后必须跟可见行为、物件或声音。

## 按任务读取参考

- 创作或改写完整剧本前，读取 `references/self-media-retention.md` 和 `references/script-and-handoff-template.md`。
- 只有故事种子、需要换题或故事中段乏力时，读取 `references/story-engines.md`。
- 涉及真实事件、网友投稿、现有爆款二创、医疗、未成年人或可识别人物时，读取 `references/reality-and-originality.md`。
- 用户要求继续交给万物生制作时，必须使用 `references/script-and-handoff-template.md` 中的 `WANWUSHENG_HANDOFF_V1`。

## 请求路由

### 从故事种子创作

先提取不可替换的情感事实，再补人物目标、反常行为、证据链和当下选择。信息不足但不影响方向时，明确标记合理假设并继续。

### 真实/网友案例改编

先建立来源台账，将可用事实与原作者表达分开。改变可识别隐私；不得用戏剧化补写冒充事实。

### 爆款或现有剧本二创

先提取机制，再更换核心因果链。至少改动关系、目标、反常行为、误解、阻碍、场景、物件、揭示、高潮或结局中的五项；仅换姓名和地点判为不合格。

### 剧本诊断/改稿

保留成立的人物、动作、台词和道具。按影响顺序修补钩子、目标、证据、反转、行动和余韵，不默认整篇重写。

### 只做自媒体包装

不篡改故事事实。只输出三种开场候选、标题、发布文案、封面短句和互动问题，并说明各自承诺了什么。

## 核心工作流

### 1. 锁定任务卡

记录：

- 输入来源与可用范围；
- 平台、目标时长、画幅和受众；
- 亲情/爱情/友情/陌生人互助等关系；
- 想让观众最终重新理解什么；
- 对白、旁白、第一人称 POV、多版本和制作限制；
- 必须保留、允许改动和禁止使用的元素。

用户未给时长时，默认输出 75-100 秒母版，并标记 60 秒可压缩节点；用户给定时长优先。

### 2. 建立事实与原创边界

把输入拆为：

1. 可核验事件事实；
2. 当事人主观说法；
3. 原作品受保护的表达；
4. 为新剧本补写的虚构；
5. 需要查证或脱敏的内容。

二创时先写一句“只复用的机制”和一句“必须重做的因果链”。

### 3. 锁定情感命题

用一句可争辩、可被行动证明的话表达主题，例如：

```text
真正的告别不是说再见，而是允许对方带着自己的选择离开。
```

避免“要珍惜家人”“母爱伟大”等无法指导剧情的口号。所有主要人物都应有当下目标；反派或阻力人物也要有可理解的现实逻辑。

### 4. 构建故事发动机

优先使用：

```text
正在发生的现实压力
+ 一个可重复拍摄的反常行为
+ 一个观众会自然产生的误判
+ 至少三条来源不同的递进证据
+ 一个能重解释前文的真相
+ 真相后需要付出代价的选择
+ 一个前后意义变化的普通物件
```

从 `references/story-engines.md` 选择一个主发动机。不得用一段录音、遗书或病历一次性解释全部故事。

### 5. 通过七步证据链

依次验证：

1. 表层事实：观众看懂眼前发生什么；
2. 表层判断：主角或观众现在相信什么；
3. 第一异常：细节与旧判断冲突；
4. 第二异常：只揭开一部分，并提高代价；
5. 核心证据：物件、行为、时间或他人见证共同支持；
6. 真相重构：至少重写三个前文镜头的意义；
7. 当下行动：主角基于新认知做选择，而不是只哭或说主题句。

证据至少包含一个物件证据、一个行为证据，以及一个时间记录或他人见证。

### 6. 编排自媒体节奏

把 `references/self-media-retention.md` 的规则写进节拍：

- 前 3 秒出现具体画面、动作、结果或扎心问题，不铺背景；
- 前 15 秒出现第一冲突、反转或明确的信息差；
- 采用“压—扬—爆—收”，不全程哭、不从第一秒铺悲情音乐；
- 植入 1-3 个群体记忆点，必须推动人物关系；
- 用手、呼吸、停顿、磨损、未完成动作等细节代替喊口号；
- 真相揭晓后留 1-2 秒无旁白停顿；
- 结尾先完成故事，再将互动问题放在发布包装层，不让角色突然替账号求评论。

### 7. 写成可拍的完整剧本

使用 `references/script-and-handoff-template.md`。每场写清：时间、地点、人物、可见动作、对白/旁白、环境声/动作声、道具状态、情绪功能和版本标记。

对白遵循：

- 重话轻说；
- 人物说自己会说的话，不替作者总结；
- 同一信息不由画面、旁白和对白重复三次；
- 峰值台词尽量短，允许被动作打断；
- 方言、年代语汇和职业细节有依据再用。

### 8. 做自媒体包装

提供：

1. 三种 3 秒钩子：结果前置、强情绪画面、扎心反问；
2. 3-5 个标题，分别偏悬念、关系、细节或共同经验；
3. 一条不剧透核心真相的发布文案；
4. 6-12 字封面短句；
5. 一个与主题有关、不过度索取创伤故事的互动问题。

钩子不得承诺剧本没有兑现的结局，不用“看哭全网”“最后一秒泪崩”等自我评价替代内容。

### 9. 评分与硬闸门

满分 100：开场 15、共同经验 10、人物目标 10、道具 10、证据链 15、反转 15、真相后行动 10、影像可执行性 5、多版本可剪性 5、事实/原创/伦理 5。

- 85-100：可交给万物生制作；
- 75-84：修补最低分项后交接；
- 65-74：保留孵化；
- 0-64：不进入资产生成。

出现以下任一项时停止交接并先修剧本：

- 反转没有递进证据；
- 只有受苦，没有目标和选择；
- 真相依赖未铺垫的新人物、绝症、身份或文件；
- 主要情绪来自羞辱或消费弱者；
- 真实人物、脸、声音或私密信息未获授权/未脱敏；
- 与参考作品只改了表面元素；
- 关键剧情依赖 AI 准确生成病历、公安通知或聊天长文。

### 10. 交给万物生

当总分达到 85，或用户明确接受修订后的剧本时：

1. 冻结 `来源事实`、人物关系、时间线、核心道具、关键台词和结局；
2. 输出 `WANWUSHENG_HANDOFF_V1`；
3. 明确 `不得改变` 与 `允许导演设计`；
4. 将关键可读文字列入后期合成，不要求生成模型直接写字；
5. 请求 `wanwusheng-ai-film-director` 从连续性审计开始，而不是跳过审计直接写视频提示词。

导演可重构镜头，不得无声修改锁定故事事实。若导演发现制作不可行，返回本技能做最小剧本修订，再重新冻结版本。

## 默认交付

按任务最小化输出；完整创作默认包含：

1. `创作判断与来源状态`
2. `一句话故事、命题与共同经验`
3. `人物目标与故事发动机`
4. `七步证据链`
5. `分时节拍表`
6. `完整可拍剧本`
7. `自媒体包装`
8. `评分、硬否决与风险`
9. `WANWUSHENG_HANDOFF_V1`

如果输出较长，先交付故事卡、证据链和节拍表；同一轮可继续完成剧本与交接包。不要在中途把未定稿内容伪装成锁定版本。

## 最终检查

- 3 秒钩子具体且诚实；15 秒内出现信息差。
- 主角目标、反常行为、误判、三条证据、真相和行动形成完整因果链。
- 反转能重解释至少三个前文细节。
- 核心道具在反转前后意义变化，并在结尾完成回收。
- 情绪由证据和选择产生，而非全程哭喊、配乐或苦难堆叠。
- 二创已改变核心因果链和至少五个维度。
- 真实来源、虚构补写、隐私、医学/法律待核验项已标注。
- 互动文案留在发布包装层。
- 交接包与最终剧本一致，没有新增事实；万物生仍能判断下一步。
- 未提供的画幅、视觉风格和对白同步方案保留为制作推断或 `director_decides`，没有伪装成用户锁定。
