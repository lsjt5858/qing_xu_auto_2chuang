# 镜流工坊 · 第一版控制台设计

本轮交付是可点击的设计原型。先确认布局和交互，再接入现有 Python 能力与 Chrome 发布插件。

## 打开原型

当前预览地址：<http://127.0.0.1:8765>

不需要安装依赖，也可以直接用浏览器打开 `index.html`。需要重新启动预览服务时，在仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory design/workbench-v1
```

页面使用示例数据。任务、配置和发布记录只在当前页面会话中保留，刷新后复原。

## 可体验的内容

| 页面 | 主要交互 |
| --- | --- |
| 工作台 | 查看当前任务、待办、最近素材，打开任务与素材详情 |
| 素材库 | 搜索、类型筛选、网格/列表切换、多选，查看镜头与转录示意 |
| 任务中心 | 三步新建任务、批量任务、筛选、暂停、继续、重试、查看阶段与日志 |
| 混剪工作室 | 模板、素材池、种子、固定选片、逐镜头查看、输出选项、创建混剪任务 |
| 成片与发布 | 区分成片/预览/草稿，编辑标题文案，预填或直接发布，确认与模拟回执 |
| 设置 | 目录、模型、复用偏好、原始长镜头偏好及演示连接状态 |

建议体验顺序：

1. 素材库选择两个视频，点击“创建处理任务”。
2. 选择处理选项，确认后进入任务中心。
3. 查看一个进行中的任务，暂停、继续，或推进演示阶段。
4. 混剪工作室修改随机种子，生成选片方案，再创建任务。
5. 成片与发布核对内容，体验预填与直接发布的不同确认流程。

发布模式切换、编辑文案或更换成片会取消之前的确认；剪映草稿没有发布按钮。

## 验证

已在浏览器中操作验证：

- 搜索、列表切换、多选与批量创建。
- 语义分镜自动补齐切镜、转录前置步骤，按处理顺序显示。
- 暂停、继续、失败重试、空状态筛选。
- 相同种子和配置得到同一选片方案；创建任务保存该方案。
- 修改混剪配置后，创建按钮要求先重新生成方案。
- 预填回执、直接发布二次确认、取消不提交、修改后重新确认。
- 草稿不可直接发布、设置会话内保留、Esc 关闭与背景焦点恢复。
- 1440px、1280px、390px 布局；窄屏导航与新建任务弹窗。
- 8 份 SVG XML 可解析，保留原生文字与形状，无外部图片。
